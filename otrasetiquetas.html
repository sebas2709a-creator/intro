```html OTRAS ETIQUETAS HTML

OTRAS ETIQUETAS HTML

REGRESAR

1. <abbr>

Descripción: Se utiliza para representar una abreviatura.

Ejemplo:

HTML

2. <address>

Descripción: Contiene información de contacto del autor o propietario de una página.

Ejemplo:

Contacto: ejemplo@gmail.com

3. <cite>

Descripción: Se utiliza para indicar el título de una obra.

Ejemplo:

Mi libro favorito es El Principito.

4. <code>

Descripción: Representa una parte de código de computadora.

Ejemplo:

Utiliza print("Hola") para mostrar un mensaje.

5. <pre>

Descripción: Muestra texto conservando los espacios y saltos de línea.

Ejemplo:

Hola
Mundo
HTML

6. <sub>

Descripción: Muestra un texto pequeño debajo de la línea normal.

Ejemplo:

H2O

7. <sup>

Descripción: Muestra un texto pequeño por encima de la línea normal.

Ejemplo:

102

8. <mark>

Descripción: Resalta una parte importante del texto.

Ejemplo:

Este es un texto importante.

9. <q>

Descripción: Se utiliza para colocar una cita corta.

Ejemplo:

Mi profesor dijo: Hay que practicar HTML.

10. <em>

Descripción: Da énfasis a una parte del texto.

Ejemplo:

Es muy importante aprender HTML.

11. <strong>

Descripción: Indica que un texto tiene gran importancia.

Ejemplo:

Importante: Guarda tu archivo.

12. <b>

Descripción: Hace que el texto aparezca en negrita.

Ejemplo:

Este texto está en negrita.

13. <i>

Descripción: Muestra un texto en cursiva.

Ejemplo:

Este texto está en cursiva.

14. <u>

Descripción: Muestra un texto subrayado.

Ejemplo:

Este texto está subrayado.

15. <s>

Descripción: Representa información que ya no es correcta o relevante.

Ejemplo:

Precio anterior $500

16. <br>

Descripción: Inserta un salto de línea.

Ejemplo:

Primera línea
Segunda línea

17. <hr>

Descripción: Crea una línea horizontal para separar contenido.

Ejemplo:

Texto arriba

Texto abajo

18. <span>

Descripción: Sirve para seleccionar una parte específica de un texto.

Ejemplo:

Este es un texto seleccionado.

19. <div>

Descripción: Se utiliza para agrupar contenido dentro de una página.

Ejemplo:

Este contenido está dentro de un div.

20. <data>

Descripción: Relaciona un contenido visible con un valor que puede ser interpretado por una computadora.

Ejemplo:

Producto: Computadora

FIN DE LAS 20 ETIQUETAS

```
