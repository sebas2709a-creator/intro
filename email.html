El Elemento <input type="email">

Guía completa y interactiva de todos sus atributos, validaciones nativas y ejemplos en tiempo real.

Atributos Soportados

value String

Define el valor inicial o predeterminado que aparecerá dentro del campo de correo electrónico al cargar la página.

placeholder String

Muestra un texto guía o pista tenue dentro del campo cuando está vacío para orientar al usuario (ej. correo@ejemplo.com).

required Booleano

Indica que el campo es obligatorio. El formulario no podrá enviarse si el input se encuentra vacío.

pattern Expresión Regular

Establece una expresión regular (Regex) que el texto ingresado debe cumplir obligatoriamente para ser válido.

minlength maxlength
Número

Limitan la cantidad mínima y máxima de caracteres permitidos en el campo de texto.

size Número

Determina el ancho visual del input medido en cantidad de caracteres visibles (por defecto suele ser 20).

autocomplete Token

Habilita o deshabilita el auto-rellenado del navegador (ej. email o off).

list ID de <datalist>

Asocia una lista de sugerencias predefinidas mediante un elemento <datalist>.

readonly disabled
Booleano

readonly: Permite leer/seleccionar pero no editar. disabled: Desactiva completamente el campo y no se envía en formularios.

autofocus Booleano

Selecciona y enfoca automáticamente este campo de entrada al cargar la página en el navegador.

Código HTML utilizado: 
<input 
  type="email" 
  value="usuario@correo.com"
  placeholder="tucorreo@dominio.com"
  required
  pattern="[a-z0-9._%+-]+@[a-z0-9.-]+\.[a-z]{2,}$"
  minlength="10"
  maxlength="50"
  size="30"
  autocomplete="email"
  list="sugerenciasDominios"
>
